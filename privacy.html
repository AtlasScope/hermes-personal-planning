Privacy policy

Effective October 20, 2026. Hermes Personal Planning is operated by Austin Whitley for personal use.

Information accessed and purpose

With Google authorization, the assistant accesses calendar names and identifiers, event details, and Google Tasks lists and task details. It uses this information to answer planning requests and create, update, complete or remove planning items as instructed. Selected Slack task text and source links can be copied into Google Tasks.

Storage and processing

Google authorization credentials are stored in a restricted local folder on the operator’s computer. Calendar and task data remain in Google; selected content may also appear in local Hermes conversation history, task-source records, and the operator’s chosen Slack conversations. Information included in an assistant request may be processed by the AI provider configured in Hermes. The operator should use only providers and settings appropriate for the information being processed.

Sharing and limitations

The tool does not sell Google user data or use it for advertising. Data is used to deliver the requested personal planning features. Hermes Personal Planning’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This information website

These static pages are hosted on GitHub Pages. They do not request Google sign-in or receive calendar/task data. GitHub logs visitors’ IP addresses for security under its own privacy practices. Do not post private planning data or credentials in public GitHub issues.

Retention and control

Google retains calendar and task content under the account’s controls. Local credentials remain until removed or revoked; local conversation and task-source records remain until the operator deletes them. Revoking access stops future authorized API access but does not erase previously created Google items or local records. Access may be revoked through the Google Account third-party connections page. The operator can delete local records and remove copied items in Google or Slack separately.

Contact for questions or deletion requests: Contact the operator through this project.
