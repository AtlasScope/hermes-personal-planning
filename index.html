Hermes Personal Planning

Austin Whitley’s personal, locally operated planning assistant. It connects Google Calendar and Google Tasks to a private Hermes workflow, including tasks selected from Slack.

The assistant can list calendars, read and update events, and organize Google Tasks when instructed. It does not request Gmail or Google Drive access. This is a personal tool, not a public sign-up service.
